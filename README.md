## Selected work

### [KosherKotlin](https://github.com/elfifo4/KosherKotlin) — Kotlin Multiplatform library on Maven Central

A Kotlin Multiplatform library for Jewish calendar and zmanim calculations, targeting Android, iOS,
desktop JVM and JavaScript. It is a port of [KosherJava](https://github.com/KosherJava/zmanim),
forked from [Sternbach-Software/KosherKotlin](https://github.com/Sternbach-Software/KosherKotlin).
My work on it: extracting the library into a standalone Gradle module, publishing it to Maven
Central as [`io.github.elfifo4:kosherkotlin`](https://central.sonatype.com/artifact/io.github.elfifo4/kosherkotlin),
toolchain and dependency upgrades, and calendar fixes backed by regression tests against the
reference Java implementation.

### Bible Contest – Tanakh Quiz (HaRishon BaChidon) — Android app, owner and sole developer

An educational quiz app for Israel's Bible Contest, written in Kotlin and published on
[Google Play](https://play.google.com/store/apps/details?id=com.eladfinish.jewishbiblecontest).
Its question data comes from [chidon-hatanach-data](https://github.com/elfifo4/chidon-hatanach-data),
a public dataset I extract from the official Ministry of Education questionnaires.

### Emoji Letter Maker — consumer Android app

An Android app I created and grew to more than 3 million downloads before it was acquired.
It is still available on [Google Play](https://play.google.com/store/apps/details?id=com.eladfinish.emojilettermaker)
under its current owner.

### [Bible-RAG](https://github.com/elfifo4/Bible-RAG) — retrieval-augmented generation over the Hebrew Bible

A RAG system with hybrid dense and lexical retrieval, Hebrew text normalization, citation-grounded
answers, an evaluation suite with ablations, and a tool-using agent on top. Python, FastAPI, FAISS
and React. Built as a course project at Ben-Gurion University.
